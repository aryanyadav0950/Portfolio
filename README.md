# 🌐 Personal Portfolio Website       
  
This is my **personal portfolio website** built using **HTML and CSS**.      
It showcases my skills, academic projects, and contact information in a clean and responsive layout.  

The portfolio is designed to give recruiters and collaborators a quick overview of my background and work.
 
---  

## 🚀 Features 

- Clean and modern UI  
- Responsive design for different screen sizes  
- Sections included:   
  - About Me
  - Skills 
  - Projects 
  - Contact Information
- Direct links to GitHub and LinkedIn
- Easy to host using GitHub Pages

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Basic JavaScript (optional / for future enhancements)

---

## 📂 Project Structure

```
Portfolio/
 ├── index.html
 ├── style.css
 └── README.md
```

---

## ▶️ How to Run Locally

1. Download or clone the repository  
2. Open the project folder  
3. Double-click `index.html`  
4. The portfolio will open in your browser
